# 💼 JobConnect Portal

JobConnect is a full-stack web application designed to connect job seekers with employers. Built with a robust **Django REST Framework (DRF)** backend and a responsive, modern frontend interface, it features complete user authentication, role-based job posting, and interactive job application tracking.

---

## 🚀 Features

* **User Authentication:** Secure registration, login, and Token-based authentication (`/api/token/`).
* **Job Management:** Browse available job listings, view detailed job descriptions, and post new job opportunities dynamically.
* **Application Tracker:** Seamlessly apply to jobs with resume links and track application status.
* **Admin Dashboard:** Full Django administration panel for managing users, groups, listings, and applications.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django, Django REST Framework (DRF)
* **Frontend:** HTML5, JavaScript, Tailwind CSS
* **Database & Tools:** SQLite, Git, VS Code, Live Server
